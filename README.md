# Wirewright

**Gets the wire right.**

Wirewright is a TypeScript-first tool for testing APIs. You can use it two ways:

- **Drop it into what you already have.** Keep Vitest, Jest, Playwright `request`, SuperTest or plain `fetch`, and hand Wirewright the response. You get typed `res.json`, schema and OpenAPI checks, and failures that tell you which field broke and why.
- **Or use it on its own.** It has a fluent HTTP client and a CLI runner, so you can write and run API tests without setting anything else up.

Either way, the goal is the same: fewer hand-written checks, and errors you can read.
